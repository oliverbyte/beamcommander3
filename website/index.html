Laser Show Control, Built for Laser Operators

BeamCommander3 drives real laser projectors from a touch-friendly web interface for shapes, colors, movement, and 128 instantly-recallable cues — with optional MIDI controller or foot pedal support. No coding needed.

💎 Free & Open Source 🌐 Runs in Any Browser 🎛️ Akai APC40 mkII Ready 🔌 Multi-Laser & Zoning 🖥️ macOS & Windows

Built For Laser Operators

Whether you're running a one-laser rig or a multi-projector show, BeamCommander3 is the remote control.

🎚️

Live Show Operators

Run shows in real time from a laptop: arm lasers, tweak shapes/colors/movement on the fly, and flash or blackout instantly when the moment calls for it.

🎪

VJs & Performers

Drive the whole show from an Akai APC40 mkII (or the web page) — tactile knobs and buttons for hands-on control during a live set.

🏗️

Installation & Rig Techs

Calibrate each physical laser's pan/zoom independently with the Zoning panel, so multiple projectors can each cover a different part of a venue.

🧑‍💻

No Coding Required

Everything above is driven from one web page — download a build, open your browser, and you're ready. Source available for anyone who wants to extend it.

Current Functionality

Everything needed to run a real show, live.

🔷

Shapes & Live Preview

See a separate movable beam source for every configured laser. Shape and movement choices show icons with labels, and the touch-friendly faders are easy to adjust by finger. Preview beams follow per-laser mirroring and armed state, and keep running when hardware is disconnected.

🌈

Color, Rainbow & Movement

Choose pure red, green, or blue alongside the other color presets, or fade from the current color into an animated rainbow, with ever finer color bands as you turn it up. Circle, pan, tilt, eight, and other movement patterns are adjustable instantly.

〰️

Movement & Rainbow Phasing

Set a phase step per laser to stagger a shared movement pattern across the installation order. Laser 1 starts at 0°; each following laser adds one step. The rainbow phase does the same for color: new colors run from laser to laser, left to right.

💾

128 Cue Slots

Save and recall looks in a resizable 16x8 grid. Cue icons preview shape, color, and motion; the cue matching the current show is outlined in bright green.

🎛️

Magic Touch

Build your own control surface from faders, knobs, pads and X/Y pads: drag, resize and snap elements into place, assign any function, invert values or use a logarithmic curve, make cues momentary, and double-tap to reset. The layout is shared by every connected device, and it comes with a ready-made live layout and example cues.

🔌

Multi-Laser Support

Add lasers by name and IP, arm them independently, and drag to reorder. Installation order controls phase offsets and MIDI numbering. The status shows whether each controller really answers, and the connection handling protects Ether Dream DACs from lock-ups.

🗺️

Per-Laser Zoning

Pan/scale each armed laser's output independently to fit its physical sub-region (a wall, a truss segment) — without touching the on-screen preview or other lasers.

🎛️

MIDI & Foot Pedal

Plug in an Akai APC40 mkII for hands-on faders and buttons matching the original BeamCommander's exact layout, or wire up a foot pedal as a brightness switch.

👆

Touch-Friendly Controls

Dedicated views keep controls organized, with larger faders and labeled shape and movement icons. On iPad and other tablets there is no copy/paste pop-up when pads are hit repeatedly, and two fingers scroll large layouts.

⚡

Flash & Blackout

Punch to full white brightness while held, or force the real laser dark instantly — the on-screen preview keeps playing either way.

🖥️

Cross-Platform Installers

Packaged builds for macOS (.dmg) and Windows (.exe installer) — no compiler or Node.js needed to just run a show.

⚠️ Laser Safety Comes First

This software can drive a real laser at full power the instant it is armed with Blackout off. Class 3B/4 laser projectors are not toys and can cause permanent eye injury.

BeamCommander3 is also experimental and under active development — it hasn't been audited or hardened for professional/production use. Run it as a hobby project, keep a human supervising the beam at all times, and never rely on it unattended.

  • Never look directly into the beam or aperture, at any distance.
  • Never point the beam at audience eye level unless the rig is professionally certified for full-audience scanning.
  • Calibrate (including the Zoning panel) with the beam aimed at a wall, floor, or beam dump — never at a person or reflective surface.
  • Blackout and the brightness gate are software conveniences, not certified safety interlocks.
  • Know and follow your local laws and regulations for laser show operation.

Read the full safety section in the README before connecting real hardware.

Get Started

No compiler, Node.js, or source checkout needed to just run a show.

🍎 macOS

Download the .dmg from the latest release, drag BeamCommander3 into Applications, and right-click → Open the first time (unsigned build).

🪟 Windows

Download and run the installer from the latest release. SmartScreen may warn once — click More info → Run anyway.

⚙️ From Source
